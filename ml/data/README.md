# ml/data/ — not in git

The 34 GB of imagery lives outside the repo.

| Subdir | What | Where |
|---|---|---|
| `raw/` | 32 GB of source datasets, unmodified | not hosted — reconstructible from the public sources listed in `docs/PROJECT_RECORD.html` §15 |
| `splits/` | 2.1 GB — the assembled, preprocessed train/val/test tiles | Hugging Face dataset repo — [rehan9599/drishti-sss](https://huggingface.co/datasets/rehan9599/drishti-sss) |
| `processed/`, `synthetic/` | intermediate build outputs | regenerated by `ml/scripts/` |

Rebuild `splits/` from scratch:
```bash
python ml/scripts/tile_subpipe.py
python ml/scripts/tile_ai4shipwrecks.py
python ml/scripts/build_dataset.py
python ml/scripts/build_synthetic_data.py --classes 3 --split train --count 900   # + val/test
python ml/scripts/build_synthetic_data.py --classes 4 --split train --count 350
python ml/scripts/preprocess_splits.py
```
