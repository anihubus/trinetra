03 Pipeline & dependencies — why Module 3 is the critical path

04 Action sequence

  1. Module 3 — geotag & report ML lead now

    Parse AURORA's XTF + navigation.csv (position, heading, altitude, range scale, ping time). Project each detection: tile row → ping → vehicle fix; tile column → slant range → ground offset → absolute lat/lon. Emit one record per hazard in schema.py as JSON + CSV, each with an audit pointer back to its source ping.

  2. In parallel — three cheap wins split now

    a. Per-class calibrator rework in calibrate_confidence.py (~20 min).  b. 15-min preprocess experiment: current model on preprocessed vs raw test images — decides whether preprocessing goes into the retrain.  c. Module 4 keeps building on mocks; add the class-0 filter + nc:4 to the config.

  3. Wire-up as Module 3 lands ML + FE then

    Point Module 2's shadow check at real ping geometry and measure its FP reduction on AURORA-style data. Swap Module 4's map from mock records to the live report output. Run the full upload→detect→filter→geotag→report→map path end to end once.

  4. Final retrain — one GPU-night, near the deadline ML lead last

    Bundle everything: nc=4 + AI4Shipwrecks overlap re-tile (152 → 600–1000+ tiles) + cylinder copy-paste from real chips + NonMILCO class + imgsz 896 + preprocessing baked in (if the experiment favoured it). Then re-fit the per-class calibrator (30 s) and re-run eval_module2.py. Output schema is unchanged, so nothing downstream touches this.

05 Decision gates

Retrain: yes or no? — decided after step 2b + Module 2 wire-up.
  • Skip it if shipwreck & cylinder clear ~0.75 precision at recall ~0.5 after per-class thresholding + shadow check, and preprocessing doesn't clearly help. Lock Module 1, all effort to 3 & 4.
  • Do it if either stays under ~0.6 precision, or preprocessing clearly helps. Current reading: shipwreck P .73/R .43 and cylinder P .75/R .38 are borderline → leaning do it, but only if Modules 3 & 4 are on track.
Preprocessing: in or out? — the 15-min experiment decides. If preprocessed input holds or improves mAP on the current model → bake into the retrain (train + serve together). If it drifts → keep as a Module 4 display enhancement + roadmap line.

Standing priority

Modules 3 / 4  >  retrain + preprocess  >  anything else. A working end-to-end pipeline with a P .73 detector passes the problem statement; a P .82 detector with no geotagging, report, or map does not.
