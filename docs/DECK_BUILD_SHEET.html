built & measured mAP@50 0.641 pipeline AP@50 0.99 geotag <1 m calibration error 0.037 90 ms/tile on CPU 0 GB PyTorch at the edge
Proposed solution
  • M0 · Preprocess — Lee MMSE speckle filter + CLAHE. Sonar speckle is multiplicative, so a blur would destroy the shadow edges that carry the signal.
  • M1 · Detect — YOLOv8s, anchor-free, 4 hazard classes + explicit "empty seabed" negatives.
  • M2 · Confidence & noise — per-class gate → per-class calibration → acoustic-shadow geometry check → honest 0–100 %.
  • M3 · Geotag & report — XTF ping headers → lat/lon + size in metres → JSON / CSV / GeoJSON.
  • M4 · Dashboard — upload log · live map · review queue · export.
How it addresses the problem — all 8 PS requirements
  • Ingest SSS + spatial metadata → XTF parser + nav CSV
  • Speckle · varying resolution · shadows · dropouts → M0 + SSS-tuned augmentation
  • Detect anomalies vs natural background → M1 + 500 hard-negative tiles
  • 0–100 % score, reject rock clusters → M2, ECE 0.052→0.037
  • Lat/lon + dimensions from ping headers → M3, validated <1 m
  • Structured JSON / CSV → report engine
  • UI dashboard, real-time map → M4, WebSocket per-tile push
  • Edge-deployable, offline → torch-free ONNX, 90 ms/tile CPU
Innovation & uniqueness
  • Physics beats a bigger network. A rock cluster is as bright as a wreck — only one casts a shadow. Expected length L = h·G/(H−h) is computable, so false positives are rejected deterministically. No second model, no extra data.
  • Confidence that means something. Per-class Platt calibration; a single global one made it worse.
  • Torch-free edge. ~210 MB runtime instead of PyTorch's 4.4 GB — meets the latency target on a CPU with no GPU.
  • Synthetic only where nothing real exists. No public ghost-net-in-sonar dataset exists; we generated one with modelled acoustics.
  • Human-in-the-loop by design. ≥80 % auto · 30–80 % analyst queue · confirmations become fine-tuning labels.

Deep dive · Module 2 — confidence & noise
  • Per-class gate — false positives sit far below true positives, at a different level for every class
  • Platt scaling P(correct|s) = 1/(1+e^(as+b)), fit per class on held-out data
  • Honesty metric ECE = Σ(n_b/N)·|acc_b − conf_b| → 0.052 → 0.037
  • Shadow check L = h·G/(H−h) — demote geometrically impossible detections
  • Result: shipwreck precision 0.63 → 0.73, cylinder 0.58 → 0.75
Deep dive · Module 3 — geotagging
  • image row → ping → interpolated (lat, lon, heading)
  • image column → slant range R → ground range G = √(R²−H²)
  • geodesic step G metres ⟂ heading (port −90° / starboard +90°)
  • Validated < 1 m against an independent navigation record
  • Output carries a ping_id pointing back to the exact sonar ping
training YOLOv8s, COCO-pretrained 6,405 tiles (4,775 / 780 / 850) 640 px · 120 epochs, best @ 91 RTX 4050, 2.1 h vertical flip OFF — preserves highlight→shadow polarity
4 FEASIBILITY AND VIABILITY job · "deployable, and they know its limits"
Feasibility — measured, not claimed
  • ≤100 ms edge target already met on a CPU — ~90 ms/tile, no GPU required
  • Whole stack on one 4-core VM — docker compose up, 5 services
  • Worker ~250 MB RAM; scale with --scale worker=4 → ~40 tiles/s
  • Model 44.8 MB ONNX; runtime ~210 MB vs PyTorch 4.4 GB
  • Reference platform: Iver4 900 + EdgeTech 2205 + Jetson Orin NX 16 GB
Limitations
  • Does not transfer to an unseen survey without fine-tuning
  • ghost_net trained on synthetic data — capability, not a field number
  • A detection is a search area (~±120 m), not a survey fix
  • crab_pot below the usable bar → filtered from the product
  • INT8 quantization collapsed → excluded, FP32/FP16 only
Challenges
  • No public ghost-net-in-sonar dataset exists anywhere
  • Speckle is multiplicative — blurring destroys the signal
  • Rock clusters are exactly as bright as wrecks
  • Human experts agree only 50–60 % on wreck boundaries
  • No connectivity underwater — acoustic link only
Solutions
  • Procedural generator with modelled acoustics for ghost_net
  • Lee MMSE filter — smooths flat seabed, preserves edges
  • Shadow-geometry check rejects objects sitting flush
  • Benchmark against published SOTA; report calibrated metrics at the operating point
  • Detect on the vehicle; bulk-sync on recovery
deployment path 1 Demo — one VM, compose → 2 Pilot — managed DB + CDN public map → 3 Field — Jetson FP16 / TensorRT → 4 Loop — fine-tune from confirmed detections
5 IMPACT AND BENEFITS job · "this reaches real people"
Impacts
  • Survey throughput — one vessel maps ~130 hectares a day, all of it reviewed by eye today. We filter the empty seafloor so analysts see only flagged segments.
  • Ghost-net recovery — a lost net keeps fishing for decades. Geolocated detections turn that into an extraction mission.
  • Navigational safety — pipelines, wrecks and suspected ordnance located and classified with a score an operator can trust.
  • Public access — a mobile map with live GPS puts confirmed hazards in the hands of fishers, not just survey rooms.
  • Auditability — every detection carries a ping_id back to the exact sonar ping.
Benefits
  • Analyst time → review flagged segments, not kilometres of grey imagery
  • Calibrated 0–100 % → operators set their own risk threshold, and the number means what it says
  • Offline / edge → runs onboard with no cloud and no GPU
  • JSON / CSV / GeoJSON → drops into existing GIS workflows unchanged
  • Human-in-the-loop → confirmations become training data; accuracy improves per operator
  • Environmental → faster ghost-net removal directly reduces bycatch and gear loss
